# 🌍 YouTube Video Translator with Speaker

## Features
- Paste YouTube video link 🎬
- Play video inside Streamlit 🎥
- Extract subtitles if available ✍️
- Translate subtitles into Urdu/Hindi/English 🌐
- Listen translation via Speaker 🔊

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
